Tax Automation Portal

Tax Automation portal for Badger CPA

This Portal was built by Silver Sea Analytics and LPR to help Badger Tax team streamline some of the tax processes starting 2026

User must be on Badger's network to execute the automation. Each module on the left navigation is an automation built for a specific purpose. Some are built to run in the background, but we still provide a UI to trigger automatically.

Note that all automations requiring interaction with Drake Tax will run on the automation machine rather than the user's works station.

Extract Filing Instructions

This function is designed to run automatically every night. First it queries the list of Karbon Work Item under status "Return Assembly". For each item, the Bot open Drake Tax to print out the Filing instruction sheets, then upload to the corresponding Karbon.

This UI is provided to test the function on individual client basis.

Drake Efile Status to Karbon

The solution will query Karbon to retrieve a list of work items under forms 1040, 1120-S, 1120, and 1065 with the status “Waiting for IRS/Agency”. For each work item, the system will open Drake, find the client by client ID, and check the electronic filing status of the corresponding tax return.

If Drake shows “EF Accepted” or “EF Rejected”, the system will use that current Drake status to update the job item status in Karbon. Finally, the system will send an email notification to the user indicating whether the e-file status update succeeded or failed
